# devops-netology  
  
Cодержимого файла .gitignore позволяет игнорировать следующие типы файлов:  
1. Файлы с конкретными расширениями  (Символ *)  
```*.tfstate``` или ```*.tfvars``` — будут игнорироваться абсолютно все файлы, заканчивающиеся на это расширение (в любой папке проекта). 
```*.tfstate.*.backup``` — будут игнорироваться файлы, у которых расширение двойное (например, main.tfstate.12345.backup)    
  
2. Конкретные файлы и скрытые файлы/папки  
```.terraform/``` — косая черта на конце означает, что игнорируется целиком папка с этим именем и всё её содержимое.  
```.terraform.lock.hcl``` — игнорируется один конкретный файл в корне или подпапках.  
  
3. Выборочный регистр символов (Квадратные скобки [ ])  
```[Tt]erraform/``` — будут игнорироваться папки, имена которых начинаются как с большой, так и с маленькой буквы (Terraform/ и terraform/).  
```crash.[Log][Log][S-s]``` — будут игнорироваться файлы crash.log, crash.LOG, crash.loS и т.д.  
  
4. Игнорирование во вложенных директориях (Символ **/)  
```**/plugins/*``` — будут игнорироваться все файлы, которые лежат внутри папки plugins, независимо от того, насколько глубоко в структуре проекта эта папка plugins находится (например, src/modules/plugins/file.exe).  
  
5. Исключения из правил (Восклицательный знак !)  
Если сначала идет правило ```.vscode/*``` (игнорировать всё в папке), а следом за ним ```!.vscode/settings.json``` — это значит, что вся папка будет проигнорирована, кроме одного этого конкретного файла настроек. Его Git увидит.  
  
6. Специфические символы в именах (Экранирование \ )  
```Generated\ Files/``` — экранирует пробел. Будет игнорироваться папка, в названии которой есть физический пробел: Generated Files.  
  
7. Системные и временные файлы по маске  
```~$*```  — будут игнорироваться файлы, имя которых начинается со знака тильды и доллара (обычно так маркируются временные скрытые файлы Windows/Office).  
```*~```  — будут игнорироваться файлы, имя которых заканчивается тильдой (автоматические бэкапы в некоторых текстовых редакторах Linux).
