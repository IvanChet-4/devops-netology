# devops-netology  
  
Сначала при создании репозитория выбрал пункт добавление gitignore, шаблон Visual Studio.  
Скопировал часть значений от туда, а затем пересоздал этот файл в соответствии с заданием и целевым коммитом Added gitignore.

Cодержимого файла .gitignore для Visual Studio позволяет игнорировать следующие типы файлов:  
-Результаты сборки программы и временный код  
-Личные настройки разработчика  
-Скрытый кэш самой среды Visual Studio и VS Code  
-Внешние зависимости и скачанные библиотеки  
-Логи и отчеты о тестировании  
-Секретные ключи и пароли   
  
Благодаря этому файлу в Git-репозиторий попадет только чистый исходный код.
